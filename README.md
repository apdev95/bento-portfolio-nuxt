# ⚡️ Andrea Puglisi — Portfolio & AI Solutions Engineer

> Modern, ultra-responsive Bento Grid portfolio built with **Nuxt 3**, **Vue 3**, **Tailwind CSS**, and **Generative AI** integrations.

Live website: **[andreapuglisi.io](https://andreapuglisi.io/)**

---

## ✨ Features

- **🚀 Generative AI & LLM Systems Integration**:
  - Interactive simulated AI Assistant terminal (`Ask Andrea's AI`) with real-time typewriter token streaming and preset knowledge queries.
  - Comprehensive AI Stack showcase (GPT-4o, Claude 3.5 Sonnet, Gemini 2.0, DeepSeek, Local LLMs via Ollama, Multi-Agent Workflows, RAG & Vector Search).
- **🏆 Maximum-Level SEO Architecture**:
  - Full Schema.org JSON-LD structured data graph (`Person`, `ProfilePage`, `WebSite`).
  - Rich OpenGraph & Twitter Card previews with high-resolution social sharing assets.
  - Canonical URL directives, geo-targeting tags for Ragusa, Sicily, Italy.
  - Search engine indexing directives, `robots.txt`, and XML Sitemap (`sitemap.xml`).
  - Mobile PWA / Web App Manifest (`site.webmanifest`).
- **🎨 Ultra-Sleek Glassmorphic Bento Grid**:
  - Deep OLED dark palette with subtle neon accents and ambient radial glow orbs.
  - Interactive Memoji easter egg with 17 shuffle poses and tactile animations.
  - Real-time digital + analog hybrid clock (CET/CEST) with day/night and active status indicators.
  - Live weather widget with Open-Meteo API and Sicilian landscape backdrop.
  - Instant one-click copy actions for email (`info@andreapuglisi.io`) and phone (`+39 331 149 58 34`).
  - Interactive reading modal for technical articles and insights.
- **⚡ Performance & Accessibility**:
  - Fully responsive from mobile devices to ultra-wide monitors without rigid height overflows.
  - Preloaded web fonts, optimized Core Web Vitals, and semantic HTML5 hierarchy.

- **Framework**: [Nuxt 3](https://nuxt.com/) / [Vue 3](https://vuejs.org/)

- **Animation**: [Motion One](https://motion.dev/) & CSS keyframe physics
- **SEO & Structured Data**: Unhead / Nuxt SEO Meta + JSON-LD

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/apdev95/andreapuglisi.io.git
cd andreapuglisi.io

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production server
npm run preview
```
